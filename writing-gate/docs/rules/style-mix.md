# style-mix

である体とですます体が文書内で混ざっていることを検出する｡既定の severity は error｡

## 判定の範囲

- 引用・見出し・表を除く｡
- 文書全体で少数派の文体の文を､最大 5 件まで挙げる｡
- 丁寧語の「ます」は連用形 (い段・え段) に付く｡直前がそれ以外なら本動詞なので､
  ですます体として数えない (「済ます」「励ます」)｡
- 体言止めはどちらにも数えない｡

## 設定

`rules.json` の `aggregates.style_mix` で変える｡

| キー | 既定 | 意味 |
| ---- | ---- | ---- |
| `min_sentences` | 5 | 文体を判定できた文がこれより少なければ判定しない |
| `max_examples` | 5 | 挙げる少数派の文の上限 |
